# Playable Shizuka
<img width="258" height="240" alt="Playable Shizuka" src="https://github.com/user-attachments/assets/3a9bd222-3661-4edd-ac4e-34f21891b8b5" />

### Adds:
- Full set of ported Lea combat arts to Shizuka's player file, adjusted for Shizuka animations.
- New edited versions of Shizuka's melee sprites to include chakrams and the missing 6th animation frames.
- New sprites for special attack, hovering, block pushing, chest open, landing, levelUpJump.
- Custom menu portrait and icons by Rioreur.

### What this mod does:
- Adds proper combat and animation support when you swap player configs to Shizuka.
- Adds all combat arts to Shizuka the party member (see below for more info).

### What this mod **doesn't** do:
- Edit "Shizuka0", the version of Shizuka you play as in the intro.
- Edit PVP Shizuka in any way.
- Change any dialogue or portraits. Cutscenes will always use Lea portraits, this mod is **not** a skin mod.
- Override any vanilla spritesheet files or animation files. Only the Shizuka player file is overridden.



>**Note:** This mod can be further improved. The full level-up animation and a few others are still not done, those are beyond what I was willing to do for this mod. If anyone wants to contribute additional spritework, please contact me on my discord (https://discord.gg/CsfUk9vpFq) and I will be happy to implement it. Likewise, if anybody wants to draw all of Lea's dialogue portrait expressions for Shizuka, an actual skin could be implemented.

### To play as Shizuka:
This mod does not contain a method to change characters on its own. Use the **char-select** mod.
- https://github.com/CCDirectLink/char-select

### Affects Shizuka as a party member:
Shizuka as a party member will have **all** the level 1 combat arts available to use, not just the limited moveset he has in vanilla. Additionally, if you install the **cc-combat-art-level-extender** mod, she will also be able to use level 2 and 3 combat arts as a party member.
- https://github.com/CCDirectLink/cc-combat-art-level-extender/releases

### Install Insructions:
Install from the in-game mod browser.
